Available Voice Commands

Fan:
• "Enable fan" — Turn fan ON
• "Disable fan" — Turn fan OFF

LED lamp:
• "Enable light", "Enable LED", "On LED", "Lights on" — Turn LED ON
• "Disable light", "Disable LED", "Off LED", "Lights off" — Turn LED OFF

LED strip:
• "Enable strip" — Turn strip ON
• "Disable strip" — Turn strip OFF

Automatic fan:
• "Enable automated fan" — Enable temperature-based fan control
• "Disable automated fan" — Disable temperature-based fan control

Automatic LED:
• "Enable automated LED" — Enable LDR-based LED control
• "Disable automated LED" — Disable LDR-based LED control
